# Club Check-In

Rushden & Higham RUFC's Club Check-In progressive web application.

**Live application:** https://rhrufc-mini.pages.dev

The application source code, runtime assets, Supabase Edge Functions and database migrations are maintained in this repository.

Project documentation is maintained separately on the

- [Change-Control, Security & Privacy Master Prompt](https://github.com/Knockout1992-tech/Club-Check-In/blob/docs/club-checkin-master-prompt/CHANGE-CONTROL-AND-SECURITY-MASTER-PROMPT.md) — mandatory starting point and living system record for future development and maintenance.
- [Club Operating & Recovery Guide](https://github.com/Knockout1992-tech/Club-Check-In/blob/docs/club-checkin-master-prompt/CLUB-OPERATING-GUIDE.md) — operational guidance for club users and administrators.
- [Security Review](https://github.com/Knockout1992-tech/Club-Check-In/blob/docs/club-checkin-master-prompt/SECURITY-REVIEW.md) — technical security controls, verification and outstanding governance points.
